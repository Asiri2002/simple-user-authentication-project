## 🌟 About The Project

A **modern MERN Stack Dashboard Application** with full CRUD functionality, authentication system, and file handling features.

This project includes:

- 👤 User Management (Register/Login)
- 📄 PDF Upload & Preview
- 🖼️ Image Upload System
- ⚡ Fast REST API using Node.js & Express

---

## ✨ Features

- 🔐 User Authentication System  
- ➕ Add / Edit / Delete Users  
- 📄 Upload & View PDF Files  
- 🖼️ Upload & Display Images  
- ⚡ Fast API (Node.js + Express)  
- 🎨 Animated UI (Framer Motion)  
- 📱 Responsive Dashboard

## 🔌 API Endpoints

| Method | Endpoint | Description |
|--------|---------|------------|
| POST | /api/users | Create user |
| GET | /api/users | Get all users |
| GET | /api/users/:id | Get user |
| PUT | /api/users/:id | Update user |
| DELETE | /api/users/:id | Delete user |
